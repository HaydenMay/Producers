# Portrait game preview

The early game preview is served at `/Producers/game/`. The visual scene lab remains at `/Producers/scene/`, the character lab at `/Producers/`, and the previous gameplay prototype at `/Producers/studio/`. Run `npm run dev:game-preview` locally.

The top bar shows the existing simulation's date, cash and prestige. A ring beside the date fills as time advances, and shows a pause symbol while any sheet is open. Time also pauses at the main menu, when the browser is backgrounded, or when a required decision is waiting; there is no offline catch-up. The preview uses a four-second week at 1×, with 2× and 4× testing speeds. Changing speed preserves the current week's progress and does not change the simulation. The bottom project bar shows the current production's raw points and timeline, and opens Projects; the Menu button opens a dismissible sheet with an upward animation (disabled for reduced-motion preferences). Projects lets the user pick available genres and themes on in-game screens, choose a Star and distributor when prompted, and see the release's audience and critic scores. Work-for-hire jobs run automatically when the menu is closed. People opens employee profiles, and casting cards open Star profiles with their actual skills and stable portraits.

The main menu offers Continue and New Studio; starting over requires confirmation before replacing an existing save. A new studio can opt into brief guidance on the real first-movie screens. Completion is remembered in the same browser, and the guide can be replayed for a new studio. Production approaches and cost estimates, casting and distribution comparisons, release performance, and studio cash activity use simulation values; distributor advertising is not a studio expense. Releases remain accessible during other work from the Menu. The preview saves one career in the current browser on the current device; it is not cloud sync, and clearing browser data can remove it. Reloading opens the paused main menu. An incompatible or damaged save is retained until the player confirms New Studio. Very long careers that exceed the replay save limit stop saving with a warning and preserve the previous save.

The People menu supports generated hires and training between productions, showing actual skills and pay. The Studio menu exposes the existing cash-and-prestige capacity upgrades; the room grows from four to six to eight desks, and up to eight employees appear with their matching portraits. Staff take turns leaving and returning to their desks along fixed paths; the movements are illustrative rather than general navigation. Existing simulation values, including costs, remain testing values where indicated in the design ledger. The traditional distribution versus Originals campaign question remains open (PROD-111).

# Staff contributions

During a production, each available employee's existing skill-weighted weekly work is revealed through the week in the project bar, with a brief cue above visible employees. Starting a film begins a fresh four-second week so its first contributions have time to appear. The preview forecasts the next weekly transition on a copy and reveals its exact staff deltas; it never adds a second award. The authoritative simulation, scores, other weekly events and economy still commit once at the week boundary. Larger teams use the same harness and studio-expectation balance as before. Popup/background pause and a saved partial-week clock prevent visible contributions from advancing while away.
