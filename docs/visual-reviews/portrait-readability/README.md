# Portrait readability comparison

The supplied Game Dev Story screenshots show a room filling the phone viewport while its edges are cropped. The scene lab was compared in desktop Chrome using a 390 × 844 viewport and reduced motion. The previous framing fits almost the entire office; 1.25× improves visibility; 1.4× gives the people more room while still showing the central desk layout; and 1.55× crops more of the team. A higher camera angle was also compared; it revealed more rooftops and weakened the previous cinematic direction, so the existing elevation was retained.
