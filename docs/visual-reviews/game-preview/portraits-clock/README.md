# Character profiles and studio clock

Screenshots are from desktop Chrome with software WebGL. People, employee,
casting and Star captures use iPhone 13 emulation at 390 × 844 CSS pixels;
narrow images use 320 × 640 and desktop uses 1280 × 800. They are not
physical iPhone or Safari captures.

- people.png and employee.png: employee card and matching detailed portrait.
- casting.png and star.png: Star cards and selected Star's details.
- narrow-studio.png and narrow-employee.png: narrow layout and clock indicator.
- desktop-studio.png and desktop-employee.png: wider layout.

The automated browser pass verified that each detail portrait is the same
cached image as its card, the studio stays paused while a profile is open, and
time resumes after close. The clock ring advances even when reduced motion is
selected. Physical-device performance remains unmeasured.
