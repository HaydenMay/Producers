# Studio routines and project status

These captures are from the running app in desktop Chrome with software
WebGL. The numbered sequence and active-project phone image use iPhone 13
emulation at 390 × 844 CSS pixels. The narrow image uses 320 × 640 with
reduced motion; the desktop image uses 1280 × 800.

The numbered frames show a crew member at the desk, standing, walking into
the room, turning near the front, and returning to the desk. Characters stay
within the open studio: the designer chose this for now instead of a doorway.
The active-project captures show the real timeline and raw production points.
Automated browser checks also verified that a project sheet pauses both the
clock and the scene animation. These are not physical iPhone or Safari tests.
